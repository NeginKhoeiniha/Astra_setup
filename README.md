# Astra_setup

Reconstructing data from a circular trajectory CT machine (Nikon, Waygate,...). 
Run the file (Astra_reconstruction.py). 
The path to the directory must be adjusted to the location of the data (P = './DataSet_3103/01/'
pre= '010'    # the common prefix of all the projections)

From line 25 to 44, the geometry and details from the specific CT scan have to be defined. More details are mentioned in the comments. The current values are from the CT scan from a Waygate machine in Polimi.
